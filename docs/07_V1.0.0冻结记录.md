## 版本范围

V1.0.0对应本次已完成开发及验收的个人导航网站。业务逻辑、UI、数据库Schema、Migration、测试代码不修改；未进行V3首页UI对齐。
Git当前从无提交的本地master建立首个正式提交，不改写已有历史。提交SHA由v1.0.0标签解析，避免在提交内记录自身SHA。

用户后续明确提供 https://github.com/xxstarli/dh.git 并要求将代码提交至该仓库；本次允许推送冻结提交和标签，不创建其他远端仓库，不进行网站部署或创建GitHub Release。
远端仓库检查为空且当前GitHub连接具有push权限；推送结果以最终交付说明及远端refs为准。
