## 范围与清理

app/、public/api/、database/、原有业务 JavaScript、生产配置模板、初始化与 Nginx 模板相对 v1.1.0 无改动。无 Schema、API、鉴权、安全或 PHP + SQLite 架构变化。仅主题 HTML/CSS/素材、开发路由、验证和发布元数据变化。

旧生成 PNG、五张 SVG 和重复源素材归档至本地 backups/v1.2.0/unused-source-assets/，不进入发布包。数据库、icons、私有配置、测试数据、调试证据均不进入白名单发布包。当前静态目录仅七张正在使用的主题 PNG 与 theme.css。
