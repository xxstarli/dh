> 文档版本：V1.0  
> 对应文档：`01_PRD.md`、`02_UI与交互说明.md`、`03_数据结构与业务规则.md`  
> 使用对象：Codex / 开发 / 测试  
> 本文档用于 V1 开发完成后的自检与最终验收。  
> 所有“必须项”通过后，才视为 V1 可交付。

---

# 1. 验收原则

V1 的验收重点不是功能数量，而是：

- 核心流程完整
- 页面简洁
- 交互清晰
- 数据可持久化
- 管理权限有效
- 排序逻辑稳定
- 不出现 PRD 之外的复杂功能
- UI 与确认稿整体一致

开发完成后，Codex 应：

1. 逐项检查本清单。
2. 发现问题直接修复。
3. 不只报告问题。
4. 修复后重新自检。
5. 最终输出未完成项；若没有则明确写“无未完成项”。
