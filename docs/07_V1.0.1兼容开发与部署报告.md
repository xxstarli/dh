# V1.0.1 兼容性验证结果

日期：2026-09-11

**状态：候选版本，未发布。** Sharp WASM 方案通过，但完整 CentOS 7 兼容性验证失败。未创建 v1.0.1 Tag。冻结 v1.0.0 不变。

## 实现

采用方案 A：固定 sharp 0.35.4，由 pnpm packageExtensions 声明 @img/sharp-wasm32 为必需依赖，排除可选平台原生图片包。保留所有现有图片解码、校验、缩放和 WebP 输出行为；未采用纯 JS 原文件存储方案 B。

Prisma generator 增加 rhel-openssl-1.0.x binaryTargets。业务模型、外键和 migrations 没有变化。app、components 和 lib 与 v1.0.0 无差异，鉴权、Session、SSRF 和上传校验不变。

新增 tests/icons.test.ts，tests/server.ts 支持 production E2E；新增现代 Linux 构建工作流。package.json、pnpm-workspace.yaml、pnpm-lock.yaml 记录兼容依赖，eslint.config.mjs 排除本地备份。

## 失败边界

Next.js 16.3.4 的生产启动链加载 next.config.ts 时尝试加载 @next/swc-linux-x64-gnu，报告 GLIBC_2.27 缺失，随后 Failed to load SWC binary / Failed to load next.config.ts。

虽然曾打印 Ready，实际请求未通过，不能认定完整运行成功。按任务约定遇到原生兼容失败后停止，未继续修改系统库或适配 SWC。

**V1.0.1 兼容改造仍无法满足 CentOS 7 完整生产运行。** 建议后续使用现代 Linux；本候选保留供复核，不作为已发布版本。

完整部署日志、数据校验、备份位置和运维报告仅在本地私有备份中保存，不进入版本库。
