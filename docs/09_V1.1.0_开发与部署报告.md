# V1.1.0 开发与部署报告

V1.1.0 为 CentOS 7 轻量运行版。保留 V1.0.0 产品与视觉，替换生产运行架构。原始需求、UI、V1.0.0 Tag/Commit 和兼容实验分支保持不变。

## 环境与架构

审计既有 PHP 后选择扩展齐备的 PHP-FPM 7.4.11；SQLite 3.7.17 实机验证通过。PDO SQLite、cURL、fileinfo、session、json、openssl、mbstring、zlib 满足运行要求。没有升级全局 PHP、Node、glibc 或安装 Docker。

生产为 HTTP :80 → 既有 Nginx → 既有 PHP-FPM Unix socket → PHP/PDO SQLite。HTML、CSS、Vanilla JavaScript 和本地 SortableJS；无 Composer 框架，也无 Node/Next/React/Prisma/Sharp 生产依赖。

## 实现与数据

- app 按数据访问、分类、网站、校验、鉴权、图标、DNS/Favicon、响应和视图分层；public 为唯一 Web Root。
- 直接复用 categories、sites、settings、admin_sessions；原 String/CUID ID、排序、Settings、bcrypt Hash 和旧 WebP 地址不变。
- 新建随机字符串 ID；分类/网站排序与跨分类移到末尾采用事务。非空分类禁止删除，允许重复名称和URL。
- init.php 对已有数据库只校验，不 Seed、不重建。全新库单独初始化，不含演示数据。
- bcrypt password_verify、数据库Session摘要、HttpOnly/SameSite Cookie、精确Origin/Referer、CSRF Token、共享文件锁登录限流。
- PNG/JPEG/WebP ≤2MB，signature、MIME、格式结构校验，SHA-256 文件名原样存储；支持合法 JPEG 转义和渐进式编码。
- Favicon 全DNS地址检查、固定已验证IP、逐跳验证、时间和大小限制，PNG-in-ICO提取；失败使用默认图标。

## UI 对照

以 V1.0.0 实际截图为基准，对照首页、管理、添加、编辑和手机布局。保留原CSS的内容宽度、卡片尺寸、5/4/3/2列、字号、间距、圆角和颜色。原生dialog与轻量菜单替代原组件库，用户流程一致。修复了Tab焦点越界；没有V3设计变更。未宣称不同浏览器截图像素完全相同。

## 部署与备份

Linux验证发布包后，校验整体SHA-256和逐文件manifest，再进入独立candidate，验证后切current。SQLite、icons、配置和限流状态与release分离、位于Web Root外，FPM用户仅需数据写权限，代码和配置只读，没有777。

正式库初始为0分类、0网站、1条Settings，使用SQLite一致性备份，传输前后SHA-256一致。临时验收数据使用约定前缀，测试后清理；Settings及管理密码保持原值。真实配置、数据库、图标和详细基础设施报告只保存在访问受限的私有备份，不进入Git或CI。

处理了本站既有Nginx syslog参数兼容问题，先备份、仅改本站，再nginx -t。回归期间发现旧共享FPM的请求级PHP_ADMIN_VALUE/open_basedir会影响其他站点，撤销该设置并平滑重载目标FPM后恢复；随后重新完成正式流程和原站点回归。没有修改其他站点配置，没有关闭应用鉴权、CSRF、SSRF或上传校验。

回滚方案：原子切current至已验证旧release；必要时恢复本站Nginx备份，必须nginx -t通过才reload。业务Schema未变，数据保持外置；如需恢复数据库，先停写并保留最新副本。原站占位页和配置另有完整备份。

当前正式站点采用HTTP，不启用TLS。HTTP流量未加密，不适合在不可信网络中传输管理密码或管理Session。
